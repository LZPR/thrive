数值与上限 字数 · 关键词 · 返回条数 · 记录槽位
这些数字决定模型一次能写多少、能读到多少。改完对下一次工具调用生效，已经写进去的内容不受影响。 「软提醒」只在工具返回里提一句，写入照常通过；「硬上限」会让这次写入被拒绝。 清空或填 0 等于用回默认值。 世界书条目
关键词超出只截断不拒绝；标题与正文超出会直接拒绝这次写入。默认：软 800 / 硬 1200 / 关键词 8 / 标题 60。 角色描述
按写入后的全文计算，不看单次加了多少。默认：软 1600 / 硬 2400。 读取返回
返回得越多，占用的上下文越多。正则读取只给命中片段，不给整篇； 单条正文超长时截断并标 truncated，截断之后不允许整段重写。 默认：10 处 / 3000 字 / 80 个标题 / 200 条提醒 / 正则 200 字 / 上下文 60 字。 记录与日志
记录条数既决定面板「已写入」显示几行，也决定能往回恢复几步；调小之后多出来的旧记录会被裁掉 （只影响面板里的历史，已经写进书里的内容不动）。日志只留在上下文里做"这轮调了什么"的提示， 超长直接截断。默认：10 条 / 200 字。

默认顺序
工具指令里可以用 {{desc_read}} 表示「可用时写成工具名」， {{!desc_read}} 表示「不可用时写成工具名」。所有工具宏都展开为空时，整段不注入。 十个工具名：desc_read、desc_append、desc_replace、desc_rewrite、 lore_list、lore_read、lore_add、lore_append、lore_replace、lore_rewrite。 关掉 = 由你在预设里手动放置，插件不再往提示词里塞任何东西；压缩指令仍会附在工具返回里。
日志与面板 旧日志清理 · 浮动面板外观
浮动面板 面板里是模式开关与写入记录。点输入框旁的徽章打开 / 收起；打开后拖动它的标题栏能挪到任意位置， 位置、大小和透明度按屏幕记住，与具体对话无关。
