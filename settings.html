基本设置 默认状态 · 徽章 · 连接 · 提示词
这一页只放跨对话一致的设置。按对话生效的都在徽章打开的面板里： 学习模式开关、描述存哪儿、可写书、待确认改动、写入记录。
学习只有这一个总开关，按对话记：这里只是新对话的初值， 当前这一场的开关在浮动面板最上面。
徽章是输入框旁那颗图标：点一下开 / 关浮动面板，学习开关与落点都在面板里。 强调色 = 学习模式开着，图标在呼吸 = 正在学（一场学习会话在跑）， 置灰 = 现在切了也没用（没打开对话）， 右上角数字 = 待确认的描述改动。
API 连接
学习与压缩在独立会话里跑，和聊天一样要发请求。这里决定它们用哪一份配置： 「跟随当前设置」就是聊天此刻用的那个 API；选了具体一份，就改用 ST 「连接配置」里那一份的 api / 模型 / 密钥。那一份的预设不随行—— 会话的提示词由插件自己编译。 只有聊天补全（Chat Completion）的配置会出现在这里——文本补全带不了工具。 改动只影响之后新开的会话，正在跑的那一场不会中途换路。
提示词
这些提示词只进学习会话，聊天请求里没有它们（所以也不会污染前缀缓存）。 独立窗口里的列表从上到下就是这一场会话的消息顺序，可以自由增删自建提示词、 逐条启用与角色、拖动排序。 列表里的是通用提示词：最上面一张是「通用提示词」卡（这场会话里你是谁、 擅长什么），下面是「目标内容」的两条——描述行是你能改能删的一句话， 注入位没有正文，学习时由插件把当前对话记录填进去，不能改、不能停用、不能删。 「会话开场白」是个折叠块，里面是特化提示词：学习 / 压缩各一段， 讲这一场具体怎么干（产出方式、写到哪、怎么写、这一次的要求）。 「工具列表」也是折叠块：这一版带出去的全部工具与它们的激活状态。 也可以导入 SillyTavern 预设（有损：保留正文、角色、启用状态与顺序， 忽略触发器与注入位置，丢弃世界书、角色卡这类无法发送的标记块）。 支持 {{char}} / {{user}} / {{setvar::名::值}} / {{getvar::名}} 等 ST 宏。

自动学习 判据 · 全局
两条判据是 or 关系，任一命中就在角色回复完之后、在独立会话里学一次。 它们对所有对话一致，所以放在这一页；开关是每场对话各自的事，在浮动面板里。 两条都空着也正常——那就只用面板上的「立刻学一次」。
从上次学习算起，攒够这么多条可见消息（工具日志这类系统消息不计）就学一次。 只在角色回复完之后结算，用户刚发完消息不会触发。填 0 = 不用这条判据。 上限 500：再大就不是"定期抽查"，是永远等不到。
关键词
最近一轮的 User / Assistant 消息里出现任意一个词就学一次，大小写不敏感。 中英文逗号、分号、换行、竖线都当分隔符，单个词最多取 40 字。 只看聊天消息本身，世界书 / 作者注释 / 预设里的字不算。留空 = 不用这条判据。
数值与上限 字数 · 条数 · 记录 · 学习
世界书条目
软提醒只用来在压缩面板里标记该压的内容，写入照常通过、模型也看不到它；硬上限会让这次写入被拒绝。 关键词超出只截断不拒绝，标题或正文超出直接拒绝。默认：软 800 / 硬 1200 / 关键词 8 / 标题 60。
角色描述
按写入后的全文算，不看单次加了多少。默认：软 1600 / 硬 2400。
读取返回
返回得越多，占用的上下文越多。正则读取只给命中片段，不给整篇；单条正文超长时截断并标记， 截断之后不允许整段重写。默认：10 处 / 3000 字 / 80 个标题 / 200 条提醒 / 正则 200 字 / 上下文 60 字。
学习会话
「目标内容」带的是当前对话记录（合并成一条消息）：带得越多，模型的上下文越满；带得太少， 早期的设定就看不到。超出时从最早的消息往前截，并在开头注明漏了多少条。 轮数是这一场最多来回几次——学习通常两三轮就够，调大只会让它多绕几圈。 默认：6000 字 / 6 轮。
写入记录
记录条数既是面板「已写入」显示几行，也是能往回恢复几步；调小之后多出来的旧记录会被裁掉， 只影响面板历史，书里的内容不动。默认：10 条。
