徽章是输入框旁那颗图标：点一下开 / 关浮动面板，主动与被动两个开关都在面板里。 强调色 = 主动开着，右下角亮小灯 = 对应模式开着，灯在闪 = 已挂上一次临时学习， 右上角数字 = 待确认的描述改动。
写入模块
两个模块互相独立：关掉的那个，模型看不到对应工具，插件也不会把内容偷偷塞到另一个里。 两个都关时，模型看不到任何 Thrive 工具。
两个模块都关着：没有可写的地方，请先开启至少一个。

开着时，模型的描述改动先存成一份 diff，等你在浮动面板里点「写入角色卡」才落盘； 暂存期间模型读到的是暂存版。关掉后直接落盘，只有「上一版快照」可回退。

数值与上限 字数 · 条数 · 记录
世界书条目
软提醒只用来在压缩面板里标记该压的内容，写入照常通过、模型也看不到它；硬上限会让这次写入被拒绝。 关键词超出只截断不拒绝，标题或正文超出直接拒绝。默认：软 800 / 硬 1200 / 关键词 8 / 标题 60。
角色描述
按写入后的全文算，不看单次加了多少。默认：软 1600 / 硬 2400。
读取返回
返回得越多，占用的上下文越多。正则读取只给命中片段，不给整篇；单条正文超长时截断并标记， 截断之后不允许整段重写。默认：10 处 / 3000 字 / 80 个标题 / 200 条提醒 / 正则 200 字 / 上下文 60 字。
记录与日志
记录条数既是面板「已写入」显示几行，也是能往回恢复几步；调小之后多出来的旧记录会被裁掉， 只影响面板历史，书里的内容不动。日志只在上下文里做「这轮调了什么」的提示，超长直接截断。 默认：10 条 / 200 字。

提示词 卡片顺序 · 内容
关着时，关闭学习模式会把工具从请求里撤下，tools 数组一变，前缀缓存就从工具定义处失效。 开着时工具定义一直留在请求里，改由「工具指令」说明哪些工具不能调用。
提示词卡片
拖动卡片调整顺序与落点：分界线「其它提示词」上方进系统提示词区，下方进对话尾部。 点卡片右侧的铅笔编辑内容，编辑弹窗右上角还能全屏。 不参与当前模式、或还等着触发条件的卡片，用虚线与角标标出。

日志与面板 日志 · 面板外观
发下一条消息时，把上一轮及更早的工具日志移出上下文；消息本身留在聊天里，照常显示。 关掉则按 ST 原生行为留在上下文里，看得见，但会随轮次累积、持续占 token。
浮动面板
点徽章打开 / 收起。打开后拖动标题栏能挪到任意位置；位置、大小和透明度按屏幕记住， 与具体对话无关。面板里是模式开关、待确认改动与写入记录。
