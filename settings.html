基本设置 默认状态 · 徽章
这一页只放跨对话一致的设置。按对话生效的都在徽章打开的面板里： 主动 / 被动开关、描述存哪儿、可写书、待确认改动、写入记录。
被动学习的开 / 关按对话记：这里只是新对话的初值，当前这一场的开关在浮动面板里。 判据（每 N 条、关键词）是全局的，在下一条「被动学习」里配——它们对所有对话一致。
徽章是输入框旁那颗图标：点一下开 / 关浮动面板，按对话生效的开关与落点都在面板里。 强调色 = 主动开着，Em 色 = 只有被动开着，图标在呼吸 = 已挂上一次临时学习， 右上角数字 = 待确认的描述改动。
被动学习 判据 · 全局
两条判据是 or 关系，任一命中就在下一轮挂一次学习。 它们对所有对话一致，所以放在这一页；开 / 关是每场对话各自的事，在浮动面板里。
从上次学习算起，攒够这么多条可见消息（工具日志这类系统消息不计）就挂一次。 只在角色回复完时结算，用户刚发完消息不会触发。填 0 = 不用这条判据。 上限 500：再大就不是"定期抽查"，是永远等不到。
关键词
最近一轮的 User / Assistant 消息里出现任意一个词就挂一次，大小写不敏感。 中英文逗号、分号、换行、竖线都当分隔符，单个词最多取 40 字。 只看聊天消息本身，世界书 / 作者注释 / 预设里的字不算。留空 = 不用这条判据。
数值与上限 字数 · 条数 · 记录
世界书条目
软提醒只用来在压缩面板里标记该压的内容，写入照常通过、模型也看不到它；硬上限会让这次写入被拒绝。 关键词超出只截断不拒绝，标题或正文超出直接拒绝。默认：软 800 / 硬 1200 / 关键词 8 / 标题 60。
角色描述
按写入后的全文算，不看单次加了多少。默认：软 1600 / 硬 2400。
读取返回
返回得越多，占用的上下文越多。正则读取只给命中片段，不给整篇；单条正文超长时截断并标记， 截断之后不允许整段重写。默认：10 处 / 3000 字 / 80 个标题 / 200 条提醒 / 正则 200 字 / 上下文 60 字。
记录与日志
记录条数既是面板「已写入」显示几行，也是能往回恢复几步；调小之后多出来的旧记录会被裁掉， 只影响面板历史，书里的内容不动。日志只在上下文里做「这轮调了什么」的提示，超长直接截断。 默认：10 条 / 200 字。

提示词 卡片顺序 · 内容
关着时，关闭学习模式会把工具从请求里撤下，tools 数组一变，前缀缓存就从工具定义处失效。 开着时工具定义一直留在请求里，改由「工具指令」说明哪些工具不能调用。
提示词卡片
拖动卡片调整顺序与落点：分界线「其它提示词」上方进系统提示词区，下方进对话尾部。 点卡片右侧的铅笔编辑内容，编辑弹窗右上角还能全屏。 不参与当前模式、或还等着触发条件的卡片，用虚线与角标标出。

日志与面板 日志 · 面板外观
