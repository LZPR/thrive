# Thrive · 学习模式

SillyTavern 扩展。开启后，角色会在对话过程中把值得长期保留的设定写进**世界书**和**角色描述**——但这件事**不在聊天里做**：每次学习另起一场内部会话，聊天请求里既没有插件提示词、也没有插件工具。

一个总开关：**学习模式**。开着就按判据自动学，也可以随时手动学一次。

适用版本：**SillyTavern 1.19.0**（2026-09-14）· 当前 v0.34.0 · 单人一对一对话，不支持群聊。

## 它解决什么

角色扮演里的设定常常散落在聊天记录里：你讲了三次"北境在南边"，第四次它还是不知道。Thrive 让角色把这类信息记进 ST 原生通道，下次命中关键词时自然带进上下文。

插件自己不保存任何"知识"——不建索引、不存摘要、不做向量检索。学到的内容 100% 落在 ST 的世界书与角色卡里，所以关掉插件它照样生效，卸载插件它也还在。插件侧只保留操作性状态：上次学习的结果、有没有待确认的改动、上一版备份与最近几次写入记录。

## 对话与学习分离（v0.33）

以前学习和对话共用一个上下文：学习挂在工具的递归里，于是对话要等它跑完，工具消息落在 `mes` 里，学习用的提示词还得伪装成一条用户发言留在历史上。

现在反过来（ADR-050）：**一次学习 = 一场一次性会话**。

1. 把当前对话记录合并成**一条**"目标内容"（`名字：内容`，空行分隔；超出字数上限时从最早往前丢，并在开头注明漏了多少条）。也可以不取对话，改由你在「教授」里写的那段话充当目标内容。
2. 用提示词编辑器里的卡片编译出一份预设：**学习规则** → 你的自建提示词 → **目标内容**。
3. 另起一场会话，发那句**开场白**（"学习时发送的 User 消息"）作为第一条用户消息，工具是那十个真实的世界书 / 角色描述工具。
4. 模型**只靠工具产出**：会话里的正文没人看，可以完全不写；一个工具都不调用也是正常结果（没有值得记的内容）。
5. 结束后把摘要写回对话状态，**聊天里一个字都不加**。

所以：发消息不会变慢，删改聊天记录不会弄坏学习，提示词也不再有"这一轮生不生效"这回事。

## 安装

ST 的「扩展」面板 → **安装扩展程序**，粘贴仓库地址（`git clone --depth 1` 到扩展目录）：

```
https://github.com/<owner>/thrive
```

三条硬约束：

- 必须是 **git 仓库地址**（HTTP/HTTPS），页面链接和 zip 都不行；
- 仓库**公开**（clone 不带凭证），且 `manifest.json` 在**仓库根目录**；
- 仓库名必须是 **`thrive`**——安装后的文件夹名取自 URL，设置面板模板按 `third-party/thrive` 渲染，换个名字装上去设置页会是空白。

装完在扩展列表里启用并刷新页面。之后列表里的「更新」就是 `git pull`。

**开发期**用目录联接，改完刷新即可：

```bat
mklink /J "<SillyTavern>\public\scripts\extensions\third-party\thrive" "<本仓库路径>"
```

联接与「安装扩展程序」只能留一种（目录已存在会 409）。拆联接用 `rmdir "<…>\thrive"`（不带 `/s`），**不要**用 `rm -rf`——那会顺着联接删进仓库本身。

## 前置条件

ST 左侧「AI 响应配置」里必须勾上 **启用函数调用**（Enable function calling，在 `Continue Postfix` 折叠块下面）。不勾的话 ST 的 `canPerformToolCalls` 是 false，插件会直接说"工具调用不可用"，学习无从开始。

连接方式必须是 **Chat Completion**（不是 Text Completion），并且只认 **OpenAI 形状的回复**：Claude / Gemini 原生连接下会直接报"不支持"，不猜着解析。

设置页顶部有一条**环境诊断**，不能用时会说明原因和该去哪改——先看它，再怀疑插件。

## 怎么用

**入口是输入框旁那颗徽章**：点一下开浮动面板，再点一下收起。

徽章只有三种状态，不叠新含义：强调色 = 学习模式开着；图标呼吸 = 正在学（一场学习会话在跑）；置灰 = 现在切了也没用（没对话 / 工具调用不可用）。右上角数字 = 有几份待确认的描述改动。

面板只装**作用于当前对话**的东西，从上到下：

- **学习模式**：整块可点，灯亮 = 开着。第二行跟着判据走（"还差 12 条" / "3 个词" / "未配判据"）；下面一行写着"正在学（手动 / 关键词 / 按条数触发）"或"上次学习：3 次工具调用 · 2 轮"，右边的两颗按钮是「教授」（写一段话直接教，见下）与「立刻学一次」，跑起来的时候它们换成「停止」。
- **更多设置**（默认收起）：描述存哪儿、可写书。两项都只对当前对话生效。
- **待确认**（有改动才出现）：描述改动的 diff，写入或丢弃。
- **已写入**（默认收起）：世界书每次写入的记录，展开后每条都能恢复成写入前。
- 世界书模式下「待确认」换成一块**角色描述 · 世界书条目**：显示落点与条目是否被激活。

标题栏上有两颗图标按钮：**虚拟世界书**（书页，右上角是还没保存的改动条数）与**压缩**（超长内容条数）。面板可拖动，位置与不透明度会记住；竖屏时它会自动让开输入区。

**判据**（每 N 条 / 关键词）不在这颗面板里——它对所有对话一致，住在设置页的「自动学习」组。面板只读它来算"还差几条"，并在一条都没配时指一句路。

两条判据是 **or** 关系，只在**角色回复完之后**评估：学习是独立会话，不必抢在生成之前，放在回复之后既不会和聊天抢同一个后端，也保证这一轮两边都已经落进记录。同一轮不会重复触发（记下这一轮用户消息的哈希）。

### 学习会话里发生什么

预设里那张**目标内容**卡只存描述行（默认「以下是目标内容：」），正文由插件在触发时追加；没有内容时整张卡跳过。开场白是另一件事：它在整份预设之后发出，告诉模型"这一次要你做什么"。

模型该做的判断都在默认规则里：只有工具会留下结果 / 不调用工具也没关系 / 写之前先读。它写到哪、怎么写，同样是规则的一部分——世界书放客观的大设定，角色描述放主观的小细节。

一场最多几轮、目标内容最多带多少字，在设置页「数值与上限 → 学习会话」里调。

### 教授（跳过对话，直接教）

有时你想教的东西在一段聊天里根本还没发生过：某个东西是什么、某个人物怎么样。这时不用先把它写进对话——浮动面板上点「教授」，在窗口里写一段话（可附图），它就成了这一场学习的**目标内容**，与当前对话无关。

- 只写文字、只附图片、两者都有都可以。图片贴在发给模型的那条消息里（data URL，不引用 ST 的图片目录），太大的图会先缩到 1400 px 以内。
- 走的还是同一套预设与开场白：学习规则、你的自建提示词、目标内容、开场白，顺序不变。
- 产出照样只有工具：写世界书、改角色描述。**不调用工具同样算正常**——你觉得值得记的，模型可能判断不必长期保留，那它就什么都不写。
- **不动这段对话的学习进度**：基线、"还差几条"、这一轮用户消息的哈希都不改。教一次不等于这段聊天已经被学过了，下次该按条数触发时还是要触发。
- 关掉窗口不会丢掉没写完的内容，回来接着写；「清空」才清。Ctrl+Enter 直接开始。
- 一次最多 4 张图、正文最多 6000 字（超了就截断，界面上会变色提示）——再多的材料该拆成几次教。

### 虚拟世界书

模型与真实世界书之间的一层缓冲区（ADR-047）：工具读写的都是它，真实世界书的文件、世界书编辑器、提示词前缀缓存一个字都不动，直到你点保存。

它也有一个必然的代价：**保存之前，这些内容不会进上下文**。ST 只扫磁盘上的书，所以角色不会因为缓冲区里多了三条设定就突然记起来——但会话里的模型自己能读到（工具走缓冲区），同一轮里继续追加、替换都照常。

- 入口是浮动面板标题栏上那颗**书页图标**：右上角数字 = 有几条条目被工具改过。点开是一个独立窗口，可以拖、可以按 Esc 关，关掉不会丢改动。
- 窗口里逐条列出：条目名、触发条件（关键词 + 组合方式）、正文的 **diff**（真实世界书 → 缓冲区）。只显示会记录下来的那几个参数。
- 标签分三种：**新增** / **改写** / **磁盘已变**（这条在世界书编辑器那边被你改过，保存会覆盖掉）。
- 唯一的两个动作都属于你：**保存到真实世界书**（整本替换，会再确认一次，每条留一份可恢复快照）、**丢弃缓冲区**（真实世界书不动）。
- 换可写书时若有未保存的改动会被拦住；一条都没改过的空缓冲区则跟着换书一起收掉。

### 压缩（还没接线）

压缩面板是一条贴在窗口左侧的侧栏，三个入口：浮动面板**标题栏上的压缩按钮**、设置页「面板与窗口」组里的按钮、`/thrive compress`。它列出超过软提醒的世界书条目与角色描述，可以逐条就地改。

「智能压缩」只返回"还没实现"——它将来会用**同一套框架**：目标内容换成超长条目的正文，开场白换成提示词编辑器里那段「压缩时发送的 User 消息」。现在这两段已经可以编辑，先备着。

### 斜杠命令

| 命令 | 行为 |
|---|---|
| `/thrive on` / `off` | 开启 / 关闭当前对话的学习模式 |
| `/thrive learn` | 立刻学一次（不等判据） |
| `/thrive stop` | 中止正在跑的那一场 |
| `/thrive status` | 一行摘要：学习（开关 / 判据 / 进度 / 上次结果）· 模块 · 可写书 · 待确认 · 缓冲区 · 超长 |
| `/thrive panel` | 打开浮动面板（与点徽章同一个） |
| `/thrive compress` | 打开压缩面板 |
| `/thrive prompt` | 打开提示词编辑器 |

不写动作等于 `status`。

## 设置页

分五组：**基本设置 / 自动学习 / 数值与上限 / 提示词 / 面板与窗口**。

这一页只放**跨对话一致**的设置，所以切对话时它一个控件都不会变（ADR-043 / ADR-045）。按对话生效的东西全在浮动面板里。

标签旁那颗小「?」是它旁边这项设置的完整说明——外面只留一眼能看懂的短标签，红色小字只在真出问题时出现。

写入能力不再有开关：世界书工具常在；角色描述工具两种存储模式都有（只是落点不同）。读也只读能改的那一本，不会出现「读得到、改不了」的条目。

角色描述默认写在**角色卡**上。在浮动面板「更多设置 → 描述存哪儿」切到**世界书条目（统一）**，它就改存进「与角色同名的那本世界书」里的一条固定条目 `【角色描述】`，并设为常驻；此时**可写书**被固定成这本同名书（下拉置灰）。这个模式下不做暂存、浮动面板也不给 diff（撤销靠「已写入 → 恢复写入前」）。切换**不迁移**内容。

「数值与上限」里的**软提醒**只决定"哪些内容会列进压缩面板"，模型看不到它；**硬上限**仍然会拒绝模型的写入。

## 提示词编辑器

设置页「提示词」组里只有一行摘要和一颗**打开编辑器**按钮——列表搬进了一个独立窗口，可以拖、可以按 Esc 关。

窗口里一屏列全整份预设，列表从上到下就是这一场会话的消息顺序（ADR-050）：

- **两张内置卡**：
  - **学习规则**——会话里做什么、产出走哪里、写到哪、怎么写。学习和压缩共用这一份。
  - **目标内容**——卡片里只存那句描述行，正文由插件在触发时追加。没有内容时整张卡跳过。
- **自建提示词**：右上角「新增」建一条（名称 + 正文，取消则不留半成品）；可改名、改正文、删除。内置卡不能删，只能停用，改坏了有「恢复默认」。
- **启用 / 停用**：行尾的滑块就是开关，停用只影响预设，正文留着。整行亮度跟着走——开着正常、关掉压暗并换成虚线边框。
- **角色**：系统 / 用户 / 助手三选一。相邻同角色的卡**不合并**：卡片是你自己排的，合并之后"我把它放在这一条之后"就不再是字面上的意思。
- **排序**：拖左侧抓手。没有"系统区 / 尾部"之分——这里是一列消息，不是一份聊天提示词。
- **会话开场白**（列表下面单独一段）：**学习时发送**、**压缩时发送**，各一段，作为那一场会话的第一条 User 消息。空着 = 用默认文本。它不参与排序、没有角色，固定最后发。
- **宏与补全**：正文里可以写 `{{char}}` / `{{user}}` / `{{setvar::名::值}}` / `{{getvar::名}}`，发请求前按列表顺序逐段展开，所以前一条 `setvar` 的值后一条读得到。打字时输入 `{{` 会弹出 ST 自己的宏补全。
- **全屏编辑**：正文框右上角那颗图标打开 ST 的放大编辑，Ctrl+Enter 完成、Esc 取消。
- **导入预设**（有损）：可以挑一个 ST 预设 JSON，也可以直接从列表里选 ST 现有的预设。保留名称 / 正文 / 角色 / 启用状态与顺序；触发器、注入位置、注入深度这些这里没有对应物的直接忽略；标记块（世界书 / 角色卡等没有正文的）与空条目会跳过并计数。导入把内容夹在「学习规则」与「目标内容」之间，并**整批替换**当前所有自建提示词，两张内置卡原样保留并恢复启用。

没有多预设的存储与切换——同一时刻只有一份，要留旧的先自己备份。
