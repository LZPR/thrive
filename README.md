# Thrive · 学习模式

SillyTavern 扩展。开启后，角色会在对话过程中把值得长期保留的设定写进**世界书**和**角色描述**——但这件事**不在聊天里做**：每次学习另起一场内部会话，聊天请求里既没有插件提示词、也没有插件工具。

一个总开关：**学习模式**。开着就按判据自动学，也可以随时手动学一次。

适用版本：**SillyTavern 1.19.0**（2026-09-14）· 当前 v0.40.0 · 单人一对一对话，不支持群聊。

## 它解决什么

角色扮演里的设定常常散落在聊天记录里：你讲了三次"北境在南边"，第四次它还是不知道。Thrive 让角色把这类信息记进 ST 原生通道，下次命中关键词时自然带进上下文。

插件自己不保存任何"知识"——不建索引、不存摘要、不做向量检索。学到的内容 100% 落在 ST 的世界书与角色卡里，所以关掉插件它照样生效，卸载插件它也还在。插件侧只保留操作性状态：上次学习的结果、有没有待确认的改动、上一版备份与最近几次写入记录。

## 对话与学习分离（v0.33）

以前学习和对话共用一个上下文：学习挂在工具的递归里，于是对话要等它跑完，工具消息落在 `mes` 里，学习用的提示词还得伪装成一条用户发言留在历史上。

现在反过来（ADR-050）：**一次学习 = 一场一次性会话**。

1. 把当前对话记录合并成**一条**"目标内容"（`名字：内容`，空行分隔；超出字数上限时从最早往前丢，并在开头注明漏了多少条）。手动「立即学习」可以取消读取聊天历史，只通过补充指令与图片学习。
2. 用提示词编辑器里的卡片编译出一份预设：描述方式的条件用途卡与你的自建提示词在前，**目标内容**（开始标记 + 注入位 + 结束标记）在末尾，排成一列消息。
3. 另起一场会话，发那条**开场白**作为第一条用户消息：有补充指令时为 `[用户内容]\n[学习时发送的内容]`，没有则只发学习任务文本。图片附在同条消息，并提供世界书工具及当前启用的描述工具。
4. 模型**只靠工具产出**：会话里的正文没人看，可以完全不写；一个工具都不调用也是正常结果（没有值得记的内容）。
5. 结束后把摘要写回对话状态，**聊天里一个字都不加**。

所以：发消息不会变慢，删改聊天记录不会弄坏学习，提示词也不再有"这一轮生不生效"这回事。

## 安装

ST 的「扩展」面板 → **安装扩展程序**，粘贴仓库地址（`git clone --depth 1` 到扩展目录）：

```
https://github.com/<owner>/thrive
```

三条硬约束：

- 必须是 **git 仓库地址**（HTTP/HTTPS），页面链接和 zip 都不行；
- 仓库**公开**（clone 不带凭证），且 `manifest.json` 在**仓库根目录**；
- 仓库名必须是 **`thrive`**——安装后的文件夹名取自 URL，设置面板模板按 `third-party/thrive` 渲染，换个名字装上去设置页会是空白。

装完在扩展列表里启用并刷新页面。之后列表里的「更新」就是 `git pull`。

**开发期**用目录联接，改完刷新即可：

```bat
mklink /J "<SillyTavern>\public\scripts\extensions\third-party\thrive" "<本仓库路径>"
```

联接与「安装扩展程序」只能留一种（目录已存在会 409）。拆联接用 `rmdir "<…>\thrive"`（不带 `/s`），**不要**用 `rm -rf`——那会顺着联接删进仓库本身。

## 前置条件

学习会话的 `tools` 由插件自己写进请求体，所以 **ST 那个「启用函数调用」开关不用勾**，勾不勾都一样能跑。

连接方式必须是 **Chat Completion**（不是 Text Completion），并且只认 **OpenAI 形状的回复**：Claude / Gemini 原生连接下会直接报"不支持"，不猜着解析。

会话走哪条连接由设置页的「**API 连接**」决定：默认「跟随当前设置」（就是聊天此刻用的那个 API）；也可以在 ST 的「连接配置」里挑一份专用的，让学习用便宜 / 长上下文的模型而聊天照旧。改动只影响之后新开的会话。

## 怎么用

**入口是输入框旁那颗徽章**：点一下开浮动面板，再点一下收起。

徽章只有三种状态，不叠新含义：强调色 = 学习模式开着；图标呼吸 = 正在学（一场学习会话在跑）；置灰 = 现在切了也没用（没打开对话）。右上角数字 = 有几份待确认的描述改动。

面板只装**作用于当前对话**的东西，从上到下：

- **学习模式**：整块可点，灯亮 = 开着。第二行跟着判据走（"还差 12 条" / "3 个词" / "未配判据"），旁边小字显示当前写入的角色、描述存储位置与世界书。下面一行显示学习状态与结果，右边是统一的「立即学习」入口；运行时另显示「停止」，仍可打开窗口排队。有任务在等时状态行后面多一颗「排队 N」。面板标题栏 X 关闭，徽章可重新打开。
- **更多设置**（默认收起）：描述存哪儿、可写书。两项都只对当前对话生效。
- **待确认**（有改动才出现）：描述改动的 diff，写入或丢弃。
- **已写入**（默认收起）：世界书每次写入的记录，展开后每条都能恢复成写入前。
- 世界书模式下「待确认」换成一块**角色描述 · 世界书条目**：显示落点与条目是否被激活。

标题栏上有两颗图标按钮：**虚拟世界书**（书页，右上角是还没保存的改动条数）与**压缩**（超长内容条数）。面板可拖动，位置与不透明度会记住；竖屏时它会自动让开输入区。

**判据**（每 N 条 / 关键词）不在这颗面板里——它对所有对话一致，住在设置页的「自动学习」组。面板只读它来算"还差几条"，并在一条都没配时指一句路。

两条判据是 **or** 关系，只在**角色回复完之后**评估：学习是独立会话，不必抢在生成之前，放在回复之后既不会和聊天抢同一个后端，也保证这一轮两边都已经落进记录。同一轮不会重复触发（记下这一轮用户消息的哈希）。

**同时只跑一场，多出来的排队**（最多 6 场，只活在内存里）。前一场结束（成、败、被中止都算）自动接下一场；`/thrive stop` 和面板的「停止」会把正在跑的和排着的一起停掉。切换对话会清空队列——排队的活儿写的是上一个对话的书。

### 学习会话里发生什么

预设末尾的「目标内容」区块有三段：**开始标记**、**注入位**与**结束标记**。两个标记可以改、停用或删除；注入位由插件填入聊天记录，不可改、不可停用、不可删。没有材料时整块跳过。开场白在整份预设之后发出，告诉模型这一次要做什么。

学习和压缩各自的开场白交代模型的专家身份与任务要求。预设中的描述用途卡只说明当前启用的描述方式适合什么场景，不向未启用方式提供提示。

学习开场白说明**产出方式、写到哪、怎么写**：只有工具会留下结果 / 不调用工具也没关系 / 写之前先读；世界书放客观的大设定，角色描述放主观的小细节。压缩开场白只要求返回候选正文，等待用户批准。

一场最多几轮、目标内容最多带多少字，在设置页「数值与上限 → 学习会话」里调。

### 立即学习（补充指令，可选聊天历史）

浮动面板点「立即学习」打开窗口，默认勾选「读取聊天历史」，留空指令也能直接学当前聊天。
也可以补充指令，比如「只整理地点设定」，或取消读取历史，直接教给模型一条新设定与图片。

- 只写文字、只附图片、两者都有都可以。文字和图片都能**直接粘贴**（截图 Ctrl+V 就进草稿），也可以点「图片」从磁盘选。图片贴在发给模型的那条消息里（data URL，不引用 ST 的图片目录），太大的图会先缩到 1400 px 以内。
- 聊天记录照常注入预设的目标内容区块；补充指令放在「学习时发送」之前，以一个换行连接。图片附在这条开场白上。指令中的宏在预设之后展开，仍可引用前面卡片设置的变量。
- 产出照样只有工具：写世界书、改角色描述。**不调用工具同样算正常**——你觉得值得记的，模型可能判断不必长期保留，那它就什么都不写。
- **取消读取历史时不动聊天学习进度**：基线、"还差几条"、用户消息哈希都不改；勾选且读取了记录时照常推进基线。历史为空但有指令或图片时也能开始。
- X 关闭窗口后保留文字、图片与历史选项；「清空」清文字与图片。Ctrl+Enter 直接开始；开始或排队成功才清草稿，失败时保留。
- 一次最多 4 张图、补充指令最多 6000 字；窗口超限时提示拆分，保留输入。排队时指令、图片与历史选项定型，聊天记录在实际开始时现取。

### 虚拟世界书

模型与真实世界书之间的一层缓冲区（ADR-047）：工具读写的都是它，真实世界书的文件、世界书编辑器、提示词前缀缓存一个字都不动，直到你点保存。

它也有一个必然的代价：**保存之前，这些内容不会进上下文**。ST 只扫磁盘上的书，所以角色不会因为缓冲区里多了三条设定就突然记起来——但会话里的模型自己能读到（工具走缓冲区），同一轮里继续追加、替换都照常。

- 入口是浮动面板标题栏上那颗**书页图标**：右上角数字 = 有几条条目被工具改过。点开是一个独立窗口，可以拖、可以按 Esc 关，关掉不会丢改动。
- 窗口里逐条列出：条目名、触发条件（关键词 + 组合方式）、正文的 **diff**（真实世界书 → 缓冲区）。只显示会记录下来的那几个参数。
- 标签分三种：**新增** / **改写** / **磁盘已变**（这条在世界书编辑器那边被你改过，保存会覆盖掉）。
- 唯一的两个动作都属于你：**保存到真实世界书**（整本替换，会再确认一次，每条留一份可恢复快照）、**丢弃缓冲区**（真实世界书不动）。
- 换可写书时若有未保存的改动会被拦住；一条都没改过的空缓冲区则跟着换书一起收掉。

### 压缩（还没接线）

压缩面板是一条贴在窗口左侧的侧栏，三个入口：浮动面板**标题栏上的压缩按钮**、设置页「面板与窗口」组里的按钮、`/thrive compress`。它列出超过软提醒的世界书条目与角色描述，可以逐条就地改。

「智能压缩」只返回"还没实现"——它将来会用**同一套框架**：注入位换成超长条目的正文，开场白换成提示词编辑器里那段压缩指令。现在这些都可以编辑，先备着。

### 斜杠命令

| 命令 | 行为 |
|---|---|
| `/thrive on` / `off` | 开启 / 关闭当前对话的学习模式 |
| `/thrive learn` | 直接学当前聊天（不等判据） |
| `/thrive stop` | 中止正在跑的那一场 |
| `/thrive status` | 一行摘要：学习（开关 / 判据 / 进度 / 上次结果）· 模块 · 可写书 · 待确认 · 缓冲区 · 超长 |
| `/thrive panel` | 打开浮动面板（与点徽章同一个） |
| `/thrive compress` | 打开压缩面板 |
| `/thrive prompt` | 打开提示词编辑器 |

不写动作等于 `status`。

## 设置页

分四组：**基本设置 / 自动学习 / 数值与上限 / 面板与窗口**。

这一页只放**跨对话一致**的设置，所以切对话时它一个控件都不会变（ADR-043 / ADR-045）。按对话生效的东西全在浮动面板里。

「基本设置」里还并着两小块，它们各自只有一两行，不值得各占一个折叠块：**API 连接**（会话走哪份连接配置）与**提示词**（打开编辑器的入口与一行统计）。

**API 连接**只列 ST「连接配置」里聊天补全（Chat Completion）的那几份：文本补全带不了工具，混进选项里只会让人选到一个必然失败的。选中那份后来被删掉时，下拉会留一个占位项并给一行红字，不会悄悄跳回「跟随当前设置」——那样你以为的"还用着专用模型"就是假的。

这一页**没有**环境诊断块（ADR-052）。会话能不能跑只有真发一次请求才知道：预判"工具调用不可用"只会把本来能跑的学习挡在门外，而真的发不出去时，失败原因（HTTP 状态、超时、配置不对）本来就会带着上下文回来。

标签旁那颗小「?」是它旁边这项设置的完整说明——外面只留一眼能看懂的短标签，红色小字只在真出问题时出现。

世界书工具常在；描述工具按浮动面板「更多设置 → 描述编辑方式」的多选结果提供，选择随当前对话保存。旧对话默认只开自然文本。PLists / Ali:Chat 仅在描述存于世界书时生效，切回角色卡会保留选择。

角色描述默认写在**角色卡**上。在浮动面板「更多设置 → 描述存哪儿」切到**世界书条目**后，每种方式各使用一条专属常驻条目：自然文本沿用 `【角色描述】`，PLists / Ali:Chat 各自独立，普通世界书工具不能读取或修改它们。缺少的条目自动创建，可写书固定为角色同名书；内容改动先进入虚拟世界书，用户保存后才落盘。切换**不迁移**内容，关闭方式时保留正文。

自然文本提供全文读取、追加、查找替换和重写。PLists 按分类维护属性字典，例如为 `character's persona` 加入 `kind`、`brave`；Ali:Chat 按位置维护问答列表，例如追加「What's your name? / I am …」。两者自动保存为相应文本格式；手工改成无法解析的格式时，工具会拒绝覆盖原文。

「数值与上限」里的**软提醒**只决定"哪些内容会列进压缩面板"，模型看不到它；**硬上限**仍然会拒绝模型的写入。

## 提示词编辑器

设置页「提示词」组里只有一行摘要和一颗**打开编辑器**按钮——列表搬进了一个独立窗口，可以拖、可以按 Esc 关。

窗口里一屏列全整份预设，列表从上到下就是这一场会话的消息顺序（ADR-050 / ADR-053）：

- **描述用途提示**——自然文本、PLists、Ali:Chat 各一张简短提示，只在当前对话启用且生效时发送。正文可改、可恢复默认，不能删除或停用，固定为系统消息。
- **目标内容 [开始] / [结束]**——包围本次材料的两句标记。可以改、停用或删掉；「默认顺序」能把它们放回来。
- **目标内容**——**注入位**，没有正文。读取聊天时插件把当前记录填在这里；取消读取则整个目标区块跳过。补充指令只进入开场白。注入位不能改、不能停用、不能删，固定在目标区块中。
- **自建提示词**：右上角「新增」建一条（名称 + 正文，取消则不留半成品）；可改名、改正文、删除。
- **启用 / 停用**：行尾的滑块就是开关，停用只影响预设，正文留着。整行亮度跟着走——开着正常、关掉压暗并换成虚线边框；注入位用虚线边框，它无所谓启用。
- **角色**：自建卡和边界卡支持系统 / 用户 / 助手三选一。每张卡各是一条消息，相邻同角色的卡不合并；用途卡与注入位固定为系统消息。
- **排序**：拖左侧抓手。没有"系统区 / 尾部"之分——这里是一列消息，不是一份聊天提示词。
- **会话开场白**（折叠块）：里面是**特化提示词**——**学习时发送**与**压缩时发送**各一段，讲这一场具体怎么干（产出方式、写到哪、怎么写、这一次的要求），作为那一场会话的第一条 User 消息整条发出。空着 = 用默认文本。它们不参与排序、没有角色。块首那行小字就是这条分工：列表里的是通用，这里是特化。
- **工具列表**（折叠块）：按当前对话的描述方式筛选，展示显示名、真实工具名、用途与可用状态。只读；描述方式在浮动面板选择，长度限制在设置页调整。
- **宏与补全**：正文里可以写 `{{char}}` / `{{user}}` / `{{setvar::名::值}}` / `{{getvar::名}}`，发请求前按列表顺序逐段展开，所以前一条 `setvar` 的值后一条读得到。打字时输入 `{{` 会弹出 ST 自己的宏补全。
- **全屏编辑**：正文框右上角那颗图标打开 ST 的放大编辑，Ctrl+Enter 完成、Esc 取消。
- **导入预设**（有损）：可以挑一个 ST 预设 JSON，也可以直接从列表里选 ST 现有的预设。保留名称 / 正文 / 角色 / 启用状态与顺序；触发器、注入位置、注入深度这些这里没有对应物的直接忽略；标记块（世界书 / 角色卡等没有正文的）与空条目会跳过并计数。导入内容排在目标内容区块之前，并**整批替换**当前所有自建提示词；描述用途卡、目标内容边界与开场白正文保留。

没有多预设的存储与切换——同一时刻只有一份，要留旧的先自己备份。

## 开发

维护者使用 Node 24 LTS（24.15.0+）与 npm；插件使用者无需安装开发依赖，也没有打包步骤。

```sh
npm ci
npm run check
npm test
npx playwright install chromium
npm run test:e2e
```
