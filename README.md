# Thrive · 学习模式

SillyTavern 扩展。开启后给模型一组受限工具，让它把对话里值得长期保留的设定写进**世界书**和**角色卡描述**；关闭后插件对模型和请求体完全不可见。

两种开启方式：**主动**（手动开关，一直学）与**被动**（配好判据，命中就借一轮）。

适用版本：**SillyTavern 1.19.0**（2026-09-14）· 当前 v0.22.2 · 单人一对一对话，不支持群聊。

## 它解决什么

角色扮演里的设定常常散落在聊天记录里：你讲了三次"北境在南边"，第四次它还是不知道。Thrive 让角色在对话过程中自己把这类信息记进 ST 原生通道，下次命中关键词时自然带进上下文。

插件自己不保存任何"知识"——不建索引、不存摘要、不做向量检索。学到的内容 100% 落在 ST 的世界书与角色卡里，所以关掉插件它照样生效，卸载插件它也还在。插件侧只保留操作性状态：本轮读过什么、有没有待确认的改动、上一版备份与最近几次写入记录。

## 安装

ST 的「扩展」面板 → **安装扩展程序**，粘贴仓库地址（`git clone --depth 1` 到扩展目录）：

```
https://github.com/<owner>/thrive
```

三条硬约束：

- 必须是 **git 仓库地址**（HTTP/HTTPS），页面链接和 zip 都不行；
- 仓库**公开**（clone 不带凭证），且 `manifest.json` 在**仓库根目录**；
- 仓库名必须是 **`thrive`**——安装后的文件夹名取自 URL，设置面板模板按 `third-party/thrive` 渲染，换个名字装上去设置页会是空白。

装完在扩展列表里启用并刷新页面。之后列表里的「更新」就是 `git pull`。

**开发期**用目录联接，改完刷新即可：

```bat
mklink /J "<SillyTavern>\public\scripts\extensions\third-party\thrive" "<本仓库路径>"
```

联接与「安装扩展程序」只能留一种（目录已存在会 409）。拆联接用 `rmdir "<…>\thrive"`（不带 `/s`），**不要**用 `rm -rf`——那会顺着联接删进仓库本身。

## 前置条件

ST 左侧「AI 响应配置」里必须勾上 **启用函数调用**（Enable function calling，在 `Continue Postfix` 折叠块下面）。不勾的话 ST 根本不会把 `tools` 发出去，表现为"模型完全不理会插件"。

两个隐形前提：连接方式为 **Chat Completion**（不是 Text Completion）；提示词后处理不能是丢弃工具的变体（选「无」或 `*_tools` 系列）。预设会覆盖这个开关，换预设后要复查。

设置页顶部有一条**环境诊断**，不能用时会说明原因和该去哪改——先看它，再怀疑插件。

## 怎么用

**入口是输入框旁那颗徽章**：点一下开浮动面板，再点一下收起。

- 徽章颜色表示状态：强调色 = 主动开着，Em 色 = 只有被动开着，灰色 = 都没开，图标呼吸 = 已挂上待学。右上角数字 = 有几份待确认的描述改动。
- 面板分三段：**模式**（主动 / 被动开关）、**待确认**（描述改动的 diff，写入或丢弃）、**已写入**（世界书每次写入的记录，默认收起，展开后每条都能恢复写入前）。面板可拖动，位置与透明度会记住；竖屏时它会自动让开输入区，不会压在输入框上。
- 标题栏右端是**压缩按钮**：一颗图标，有超长内容时会亮起并挂上条数角标，出现**新的**超长内容时还会闪几下（侧栏开着时不打扰，面板关着时改弹一句提示）。压缩本身不在面板里做，点它打开左侧侧栏。
- 已写入的那条描述记录带三个动作，名字就是落点：**填入编辑框**（只改角色编辑面板里的文本框，保存才生效）、**重写角色卡**（真的落盘，卡上现版先进「上一版」）、**移除记录**（只是收掉这条记录，内容不动）。

**压缩**是一条贴在窗口左侧的侧栏，三个入口都能打开它：浮动面板**标题栏上的压缩按钮**、设置页「数值与上限」组里的「压缩面板」按钮、`/thrive compress`。
它列出超过软提醒的世界书条目与角色描述，可以逐条就地改，也可以勾选多条等「智能压缩」（还没接线）。
侧栏从顶栏下方一直到底、占 420px 宽，不可拖动——位置固定，改正文时右边的聊天区照样看得见，关掉就完全还原。
标题栏那颗按钮在有内容时会亮起（带条数），有新的条目进来时闪一下，其余时候安静地待着——不会自动弹窗口，什么时候处理由你决定。设置页那颗按钮不做高亮也不做动效，只是入口。
角色描述按角色卡上**实际那份**算，暂存待应用的改动不计入。

**主动**是当前对话一直学；**被动**是全局的，按「每 N 条消息」或「关键词命中」任一成立时借一轮，回复完自动关闭，不会一直挂着。

斜杠命令：

| 命令 | 行为 |
|---|---|
| `/thrive on` / `off` | 开启 / 关闭当前对话的学习 |
| `/thrive passive` | 切换被动学习总开关（全局） |
| `/thrive once` | 给下一轮挂一次临时学习（不受总开关限制） |
| `/thrive status` | 一行摘要：主动 · 被动 · 模块 · 可写书 · 待确认数 · 超长条数 |
| `/thrive panel` | 打开浮动面板（与点徽章同一个） |
| `/thrive compress` | 打开压缩面板（超长条目与角色描述） |

不写动作等于 `status`。

**设置页**分六组：基本开关 / 被动学习 / 写入目标 / 数值与上限 / 提示词 / 日志与面板。
两个写入模块（世界书、角色描述）可以各自关掉，关掉后模型看不到对应工具，也不会被偷偷改塞到另一处。

「数值与上限」里的**软提醒**只决定"哪些内容会列进压缩面板"，不会出现在工具返回里，模型也看不到它；
**硬上限**仍然会拒绝模型的写入——写超了就是写超了，不存在"让它自己压短"这回事。

「提示词」是一列可拖动的卡片：**压缩指令 / 学习块[通用] / 学习块[主动模式] / 学习块[被动模式] / 其它提示词 / 工具指令**。拖动卡片调整顺序与落点——分界线「其它提示词」上方进系统提示词区，下方进对话尾部；点卡片上的铅笔编辑正文，弹窗右上角可以全屏编辑。不参与当前模式、或还等着触发条件的卡片（比如压缩指令）会用虚线与「未生效 / 条件触发」角标区分开。

学习块拆成三段：**通用**（两种模式都带）+ **主动** / **被动**（只带当前模式那段）。主动与被动同时成立时按主动算。被动那一轮末尾还会由插件自动补一句「本轮为自动触发」的说明，不用自己写。

**工具提示词常驻**是同一组里的开关：关着时，关闭学习模式会把工具从请求里整个撤下，`tools` 数组随之变化，前缀缓存从工具定义处失效；开着时工具定义一直留在请求里，改由「工具指令」告诉模型哪些工具不能调用（支持 `{{desc_read}}` / `{{!desc_read}}` 两种宏），调用被拦下时返回 `TOOL_UNAVAILABLE`。工具定义是请求里最大的一块，开关频繁时这个差别很明显。

「提示词」后面是一个独立分组**工具清单**（默认收起，与其它分组同级）：十个工具的中文名、工具名、描述、参数、两个宏，以及此刻的状态（可用 / 不可用 / 未注入，各带一句原因）。内容直接取自实际发给模型的工具定义，只读；点任意宏可单独复制，两个按钮分别把全部 `{{x}}` 或全部 `{{!x}}` 一次复制走。
