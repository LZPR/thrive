# Thrive · 学习模式

SillyTavern 扩展。开启后给模型一组受限工具，让它把对话里值得长期保留的设定写进**世界书**和**角色卡描述**；关闭后插件对模型和请求体完全不可见。

两种开启方式：**主动**（手动开关，一直学）与**被动**（配好判据，命中就借一轮）。

适用版本：**SillyTavern 1.19.0**（2026-09-14）· 当前 v0.31.1 · 单人一对一对话，不支持群聊。

## 它解决什么

角色扮演里的设定常常散落在聊天记录里：你讲了三次"北境在南边"，第四次它还是不知道。Thrive 让角色在对话过程中自己把这类信息记进 ST 原生通道，下次命中关键词时自然带进上下文。

插件自己不保存任何"知识"——不建索引、不存摘要、不做向量检索。学到的内容 100% 落在 ST 的世界书与角色卡里，所以关掉插件它照样生效，卸载插件它也还在。插件侧只保留操作性状态：本轮读过什么、有没有待确认的改动、上一版备份与最近几次写入记录。

## 安装

ST 的「扩展」面板 → **安装扩展程序**，粘贴仓库地址（`git clone --depth 1` 到扩展目录）：

```
https://github.com/<owner>/thrive
```

三条硬约束：

- 必须是 **git 仓库地址**（HTTP/HTTPS），页面链接和 zip 都不行；
- 仓库**公开**（clone 不带凭证），且 `manifest.json` 在**仓库根目录**；
- 仓库名必须是 **`thrive`**——安装后的文件夹名取自 URL，设置面板模板按 `third-party/thrive` 渲染，换个名字装上去设置页会是空白。

装完在扩展列表里启用并刷新页面。之后列表里的「更新」就是 `git pull`。

**开发期**用目录联接，改完刷新即可：

```bat
mklink /J "<SillyTavern>\public\scripts\extensions\third-party\thrive" "<本仓库路径>"
```

联接与「安装扩展程序」只能留一种（目录已存在会 409）。拆联接用 `rmdir "<…>\thrive"`（不带 `/s`），**不要**用 `rm -rf`——那会顺着联接删进仓库本身。

## 前置条件

ST 左侧「AI 响应配置」里必须勾上 **启用函数调用**（Enable function calling，在 `Continue Postfix` 折叠块下面）。不勾的话 ST 根本不会把 `tools` 发出去，表现为"模型完全不理会插件"。

两个隐形前提：连接方式为 **Chat Completion**（不是 Text Completion）；提示词后处理不能是丢弃工具的变体（选「无」或 `*_tools` 系列）。预设会覆盖这个开关，换预设后要复查。

设置页顶部有一条**环境诊断**，不能用时会说明原因和该去哪改——先看它，再怀疑插件。

## 怎么用

**入口是输入框旁那颗徽章**：点一下开浮动面板，再点一下收起。

- 徽章颜色表示状态：强调色 = 主动开着，Em 色 = 只有被动开着，灰色 = 都没开，图标呼吸 = 已挂上待学。右上角数字 = 有几份待确认的描述改动。
- 面板只装**作用于当前对话**的东西，从上到下：**模式**（主动 / 被动两块，横排，点整块就切换）、**更多设置**（默认收起：描述存哪儿、可写书、「现在触发一次」）、**待确认**（描述改动的 diff，写入或丢弃）、**已写入**（世界书每次写入的记录，默认收起，展开后每条都能恢复写入前）。世界书模式下「待确认」换成一块**角色描述 · 世界书条目**：显示落点、条目是否被停用、角色卡上是否还留着没被使用的描述。面板可拖动，位置与不透明度会记住；竖屏时它会自动让开输入区，不会压在输入框上。
- 标题栏上有两颗图标按钮：**虚拟世界书**（书页，右上角是还没保存的改动条数，详见下一节）与**压缩**（超长内容条数）。
- 压缩按钮在有超长内容时会亮起并挂上条数角标，出现**新的**超长内容时还会闪几下（侧栏开着时不打扰，面板关着时改弹一句提示）。压缩本身不在面板里做，点它打开左侧侧栏。
- 已写入的那条描述记录带三个动作，名字就是落点：**填入编辑框**（只改角色编辑面板里的文本框，保存才生效）、**重写角色卡**（真的落盘，卡上现版先进「上一版」）、**移除记录**（只是收掉这条记录，内容不动）。

**虚拟世界书**是模型与真实世界书之间的一层缓冲区（ADR-047）：工具读写的都是它，真实世界书的文件、世界书编辑器、提示词前缀缓存一个字都不动，直到你点保存。

它也有一个必然的代价：**保存之前，这些内容不会进上下文**。ST 只扫磁盘上的书，所以角色不会因为缓冲区里多了三条设定就突然记起来——但模型自己能读到（工具走缓冲区），同一轮里继续追加、替换都照常。

- 入口是浮动面板标题栏上那颗**书页图标**：右上角数字 = 有几条条目被工具改过，亮着就说明"真实世界书还没变，等你决定"。点开是一个独立窗口，可以拖、可以按 Esc 关，关掉不会丢改动。
- 窗口里逐条列出：条目名、触发条件（关键词 + 组合方式）、正文的 **diff**（真实世界书 → 缓冲区）。只显示会记录下来的那几个参数——order、position、probability 这些工具从来不碰，摆出来只会让人以为它们会变。
- 标签分三种：**新增** / **改写**（工具改的）/ **磁盘已变**（这条在世界书编辑器那边被你改过，缓冲区还停在旧版本，保存会覆盖掉）。未改动的条目默认收起，点底下一个按钮展开核对。
- 窗口**对外只读**：不能在这儿改正文或关键词。要改就让模型改，或者丢弃重来。唯一的两个动作都属于你：
  - **保存到真实世界书**：整本替换成缓冲区这份，会再确认一次（每条都留一份可恢复的快照，落在「已写入」里）。缓冲区开出来之后真实世界书若被别处改过，确认文案会改成"会覆盖那些改动"。
  - **丢弃缓冲区**：真实世界书不动。有改动时确认一句，空缓冲区直接收掉。
- 换可写书时若有未保存的改动，会被拦住并告诉你去哪儿处理；一条都没改过的空缓冲区则跟着换书一起收掉。
- 缓冲区里的每一笔也会进面板的「已写入」，带一个**缓冲区**标记，可以逐条恢复成"这笔之前的样子"——恢复只动缓冲区。缓冲区一保存或丢弃，这批记录自动收掉，换成保存那一下产生的真实世界书记录。

**压缩**是一条贴在窗口左侧的侧栏，三个入口都能打开它：浮动面板**标题栏上的压缩按钮**、设置页「日志与面板」组里的「压缩面板」按钮、`/thrive compress`。
它列出超过软提醒的世界书条目与角色描述，可以逐条就地改，也可以勾选多条等「智能压缩」（还没接线）。
侧栏从顶栏下方一直到底、占 420px 宽，不可拖动——位置固定，改正文时右边的聊天区照样看得见，关掉就完全还原。
标题栏那颗按钮在有内容时会亮起（带条数），有新的条目进来时闪一下，其余时候安静地待着——不会自动弹窗口，什么时候处理由你决定。设置页那颗按钮不做高亮也不做动效，只是入口。
角色描述按**当前存储模式下的实际那份**算（角色卡模式读卡上的正文，世界书模式读那条条目），暂存待应用的改动不计入。

**主动**是当前对话一直学；**被动**按「每 N 条消息」或「关键词命中」任一成立时借一轮，回复完自动关闭，不会一直挂着。两个开关都在浮动面板最上面，横排各占一半：点整块就切换，灯亮 = 开着，第二行写的是被动还差几条（没开时写 `本对话`）。两个开关都**只作用于当前对话**；判据（每 N 条 / 关键词）是**全局**的，改一次对所有对话生效——它在设置页的「被动学习」组里。切换不弹提示——状态就在被点的那一块上。

斜杠命令：

| 命令 | 行为 |
|---|---|
| `/thrive on` / `off` | 开启 / 关闭当前对话的学习 |
| `/thrive passive` | 切换当前对话的被动学习开关（判据是全局的） |
| `/thrive once` | 给下一轮挂一次临时学习（不受总开关限制） |
| `/thrive status` | 一行摘要：主动 · 被动 · 可写目标 · 可写书 · 待确认数 · 虚拟世界书待保存条数 · 超长条数 |
| `/thrive panel` | 打开浮动面板（与点徽章同一个） |
| `/thrive compress` | 打开压缩面板（超长条目与角色描述） |
| `/thrive prompt` | 打开提示词编辑器 |
| `/thrive session` | 起一场内部会话（自检用：stub 预设 + stub 工具） |
| `/thrive session stop` | 中止正在跑的那一场 |
| `/thrive session log` | 打出最后一场的完整消息与工具往来 |

不写动作等于 `status`。

**内部会话**是插件在自己内部起的一场"对话"，与当前聊天无关（ADR-049、spec §18）。它存在的理由只有一条：学习不该挂在聊天轮次上——不占你的等待、不受消息编辑与后处理影响、不与对话共用提示词。
这一版还只是**框架**：预设、用户消息、工具全是 stub，用来把「开始 → 填预设 → 发消息 → 多轮工具调用 → 结束」这五步串起来并验证隔离。跑完聊天区不会有任何新消息，刷新也不会留下痕迹（工具表、`extension_prompts`、`chat_metadata` 三处都不动）。
注意它**只认 OpenAI 形状的回复**：Claude / Gemini 原生连接下会直接说"不支持"，不会猜着解析。会话不落盘、没有界面，能看到的只有结束那一行摘要和 `/thrive session log`。

**设置页**分五组：基本设置 / 被动学习 / 数值与上限 / 提示词 / 日志与面板，后面还有一个只读的**工具清单**分块。
这一页只放**跨对话一致**的设置，所以切对话时它一个控件都不会变（ADR-045）。
按对话生效的东西全在浮动面板里：主动 / 被动开关、描述存哪儿、可写书、待确认改动、写入记录。
标签旁那颗小「?」是它旁边这项设置的完整说明——外面只留一眼能看懂的短标签，红色小字只在真出问题时出现。
写入能力不再有开关：世界书工具常在；角色描述工具两种存储模式都有（只是落点不同）。
读也只读能改的那一本，不会出现「读得到、改不了」的条目。
「被动学习」组里是两条判据：**每 N 条**（0 = 不用这条，上限 500）与**关键词**（逗号 / 分号 / 换行分隔，大小写不敏感），
两条是 or 关系，都空着时组里会写一句"被动学习开着也不会触发"。

角色描述默认写在**角色卡**上。在浮动面板「更多设置 → 描述存哪儿」切到**世界书条目（统一）**，它就改存进「与角色同名的那本世界书」里的一条固定条目 `【角色描述】`，并设为常驻——描述工具名与参数都不变，只是落点换了。此时**可写书**也被固定成这本同名书（下拉置灰），因为描述就在那儿。这个模式下不做暂存、浮动面板也不给 diff（撤销靠「已写入 → 恢复写入前」），那条条目不会出现在世界书工具的目录里，也不会被它们改写。切换**不迁移**内容：条目从空开始，角色卡上原有的字也不会被删，想只留一个来源得手动清空。

「数值与上限」里的**软提醒**只决定"哪些内容会列进压缩面板"，不会出现在工具返回里，模型也看不到它；
**硬上限**仍然会拒绝模型的写入——写超了就是写超了，不存在"让它自己压短"这回事。

「提示词」折叠块里只有两个开关（自动注入 / 工具提示词常驻）、一行摘要和一颗**打开编辑器**按钮——列表搬进了一个独立窗口，可以拖、可以按 Esc 关。

窗口里一屏列全所有提示词，每行是：抓手 · 名称 · 角色 chip · 落点与字数 · 编辑按钮 · 尾部滑块开关。

- **顺序与落点**：拖抓手调整顺序。分界线「其它提示词」上方进系统提示词区，下方进对话尾部，拖动分界线等于整体换边。
- **增删改**：右上角「新增」建一条自己的提示词（名称 + 正文，取消则不留半成品）；自建卡可改名、改正文、删除；内置卡不能删，只能停用，改坏了有「恢复默认」。名称、角色、删除都在展开后的编辑区里，卡片本身只留一列「编辑 + 开关」，各行才对得齐。
- **角色**：系统 / 用户 / 助手三选一，注入时真的按这个角色发。ST 的一条扩展提示词只带一个 role，所以插件会把**相邻且同角色**的卡拼成一段再发，角色变了就另起一段——段数因此会随顺序变化。
- **启用 / 停用**：行尾的滑块开关就是启用开关，停用只影响注入，正文留着。整行亮度跟着这个开关走——开着正常、关掉压暗并换成虚线边框，所以一屏扫过去就知道自己关了哪几条。窗口不显示「这一轮生不生效」：那个判断跟着学习模式与轮次变，没开学习时每张卡都「未生效」，反而没有信息量；想知道某条为什么没进请求，把鼠标停在那行的小字上。
- **收起**：「编辑」按钮再点一次就收起，等同一个小抽屉；改过还没保存时会先问一句。
- **宏与补全**：正文里可以写 `{{char}}` / `{{user}}` / `{{setvar::名::值}}` / `{{getvar::名}}`，注入时按列表顺序逐段展开，所以前一条 `setvar` 的值后一条读得到。打字时输入 `{{` 会弹出 ST 自己的宏补全（走的是同一份宏清单，不是插件另做一套）。
- **全屏编辑**：正文框右上角那颗图标打开 ST 的放大编辑，Ctrl+Enter 完成、Esc 取消；取消不写回草稿。
- **导入预设**（有损）：右上角「导入预设」可以挑一个 ST 预设 JSON，也可以直接从列表里选 ST 现有的预设。保留名称 / 正文 / 角色 / 启用状态与落点；触发器、注入顺序、注入深度这些这里没有对应物的直接忽略；标记块（世界书 / 角色卡 / 作者注释等没有正文的）与空条目会跳过并计数。落盘前会先弹确认框，把"导入几条、跳过几条为什么、几条核心系统提示词可能重复"逐项写清楚。导入是**整批替换**当前所有自建提示词，内置卡（学习块等）原样保留并恢复启用，不碰你的「自动注入」开关。

没有多预设的存储与切换——同一时刻只有一份，要留旧的先自己备份。

学习块拆成三段：**通用**（两种模式都带）+ **主动** / **被动**（只带当前模式那段）。主动与被动同时成立时按主动算。被动那一轮末尾还会由插件自动补一句「本轮为自动触发」的说明，不用自己写。

**工具提示词常驻**是同一组里的开关：关着时，关闭学习模式会把工具从请求里整个撤下，`tools` 数组随之变化，前缀缓存从工具定义处失效；开着时工具定义一直留在请求里，改由「工具指令」告诉模型哪些工具不能调用（支持 `{{desc_read}}` / `{{!desc_read}}` 两种宏），调用被拦下时返回 `TOOL_UNAVAILABLE`。工具定义是请求里最大的一块，开关频繁时这个差别很明显。

「提示词」后面是一个独立分组**工具清单**（默认收起，与其它分组同级）：十个工具的中文名、工具名、描述、参数、两个宏，以及此刻的状态（可用 / 不可用 / 未注入，各带一句原因）。内容直接取自实际发给模型的工具定义，只读；点任意宏可单独复制，两个按钮分别把全部 `{{x}}` 或全部 `{{!x}}` 一次复制走。
